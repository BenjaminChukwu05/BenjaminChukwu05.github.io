Privacy Policy — rclone-personal

Last updated: 30 October 2026

Operator and scope. rclone-personal is a single-user Google Drive OAuth integration operated by the maintainer of BenjaminChukwu05. It is used with the locally installed rclone application for the operator's own file backups and restores. It is not a service offered to other users.

Google data accessed

With the account owner's authorization, rclone can access Google Drive files, folders, names, metadata, and content. It uses Drive permissions to list and search existing files, upload backups, download and restore archives, and perform any additional file operations the owner explicitly invokes or configures. Because the integration must work with pre-existing backup files, it requests broad Google Drive access rather than access limited to newly created files.

How data is used

Google Drive data is used solely for the owner's local file-management, scheduled-backup, backup-verification, and recovery workflows. It is not used for advertising, profiling, marketing, training models, or sale of personal information.

Storage and authentication

Google handles account sign-in and authorization. OAuth tokens and rclone remote settings are stored in the local configuration on the owner's computer, not in this GitHub Pages website or its public source repository. Backup files remain in the locations the owner selects, including their personal Google Drive account and local storage. The owner is responsible for securing the local computer and configuration files.

Sharing and transfers

This informational website does not receive Google Drive file content or OAuth tokens. When instructed or scheduled by the owner, the locally running rclone program transfers file data between Google Drive and owner-configured storage destinations. No third party is given access to Google user data by this website. Hosting of these public information pages is provided by GitHub Pages, subject to GitHub's privacy statement.

Retention and deletion

The owner controls which local and Google Drive files are retained or deleted through rclone and Google Drive. Locally stored OAuth credentials remain until the owner removes the rclone configuration or revokes the app's access in their Google account. Removing the OAuth authorization stops future authorized access but does not automatically delete existing backup files.

Security and changes

The integration uses Google's OAuth authorization flow. The website contains no analytics scripts, login forms, or token collection mechanisms. This policy will be updated if the integration's handling of Google user data changes.

Questions

For questions about this integration or policy, contact the maintainer through their GitHub profile.

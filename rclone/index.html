Personal desktop utility

rclone-personal

This is a private, single-user integration using the open-source rclone command-line tool to access Google Drive from a personal computer. It supports file backups, archive verification, and restoration for the account owner.

What Google Drive access is used for

The integration requests Google Drive permissions so rclone can list files and folders; upload, download, copy, and manage backups; and retrieve previously saved archives. The Google account owner chooses which commands and scheduled tasks are configured. Full Drive access is needed to work with files and folders that existed before this OAuth client was created.

Where it runs

rclone runs locally on the account owner's computer. This website is an informational page only: it is not a cloud backup service, does not authenticate users, and has no upload form or application backend. The desktop integration is not offered for public use.

Privacy

The local integration uses Google account data only to perform its configured file-management and backup operations. Read our privacy policy for details about access, local credential storage, sharing, and deletion.
